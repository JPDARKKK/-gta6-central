# GTA 6 Central — static website starter

## Preview
Open `index.html` in a browser or serve the folder with `python -m http.server 8000`.

## Free hosting
1. Create a GitHub repository and upload the files in this folder (not the zip itself).
2. Enable GitHub Pages under Settings → Pages → Deploy from branch, or deploy the folder to Cloudflare Pages.
3. Test navigation, mobile layout and page load speed.
